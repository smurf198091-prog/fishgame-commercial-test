# Fishgame Commercial Test - GitHub Pages Edition

公网免费测试版本，适配 GitHub Pages。

## 访问路径

- `/` 入口页
- `/game/` 游戏端
- `/admin/` 测试后台

## 当前能力

- 完整 H5 捕鱼游戏静态文件
- 游戏画面自适应
- 测试后台页面

## 注意

GitHub Pages 是静态托管，没有云端数据库和真正服务端。当前后台只适合演示。后续如果需要真实商业后台，可以再接 Cloudflare Workers / Supabase。

## 合规边界

当前仅做娱乐币测试，不接入真钱充值、提现或博彩结算。

## 合规运营边界

本项目定位为 **海外娱乐币游戏技术演示与产品测试**，不是赌博平台。

固定边界：

- 不在中国境内开展商业运营；
- 不面向中国境内用户提供商业服务；
- 游戏币仅为体验币/娱乐币，不具备现金价值；
- 不接入支付通道；
- 不支持充值；
- 不支持提现；
- 不支持兑换现金或实物；
- 不支持用户间交易或转让游戏币；
- 不设置代理、返佣、抽水、排行榜奖金；
- 不允许线下收款、人工上分、线下结算。

允许的商业化方向仅限：广告、会员去广告、皮肤/主题、普通付费下载、非随机道具、品牌展示、试玩引流等不涉及输赢结算的模式。
