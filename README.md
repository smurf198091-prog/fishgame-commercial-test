# Fishgame Commercial Test - GitHub Pages Edition

公网免费测试版本，适配 GitHub Pages。

## 访问路径

- `/` 入口页
- `/game/` 游戏端
- `/admin/` 测试后台

## 当前能力

- 完整 H5 捕鱼游戏静态文件
- 游戏画面自适应
- 测试后台页面

## 注意

GitHub Pages 是静态托管，没有云端数据库和真正服务端。当前后台只适合演示。后续如果需要真实商业后台，可以再接 Cloudflare Workers / Supabase。

## 合规边界

当前仅做娱乐币测试，不接入真钱充值、提现或博彩结算。
